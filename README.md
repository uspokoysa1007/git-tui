# git-tui

TUI-клиент для git на Rust (ratatui) — просмотр статуса, диффов и коммитов без выхода из терминала.

## Возможности (план)

- экран статуса: изменённые/новые/удалённые файлы;
- просмотр диффов;
- stage/unstage отдельных файлов и хунков;
- коммиты с сообщением;
- просмотр лога и веток;
- горячие клавиши в стиле lazygit.

## Стек

- Язык: Rust
- Планируемые библиотеки: `ratatui`, `crossterm`, `git2`

## Сборка и запуск

```bash
cargo build --release
cargo run --release
```
